# IfaLode - Complete Babalawo Platform

A modern, full-stack web application for Babalawo with e-book store, Learning Management System (LMS), and a flexible CMS for complete brand customization.

## Features

- 📚 E-book Store with product management
- 🎓 Learning Management System for courses
- ✨ Dynamic CMS for brand customization
- 🔐 Complete authentication flow
- 👑 Admin dashboard
- 📱 Mobile responsive
- 🔍 SEO optimized

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Supabase (PostgreSQL)
- NextAuth.js
- Tailwind CSS
- Vercel

## Quick Start

1. Clone the repository
2. Install dependencies: `npm install`
3. Copy `.env.local.example` to `.env.local` and fill in your credentials
4. Run migrations in Supabase
5. Start development: `npm run dev`
